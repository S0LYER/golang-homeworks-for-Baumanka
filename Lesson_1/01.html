Язык

Что такое Go

Простота как фича

Маленький язык: мало ключевых слов, один способ писать циклы, читаемый код без «магии».

Компилируемый

Статическая типизация, быстрая сборка в один бинарник. Пишешь — собираешь — запускаешь.

Для сервисов

Родился в Google под сеть и инфраструктуру. Конкурентность и стандартная библиотека — из коробки.

Где живёт

Go в реальных продуктах

Backend, CLI и инфраструктура — не «учебный» язык, а рабочий инструмент больших систем.

Зачем нам

Почему Go на backend-треке

Скорость сборки

Короткий цикл обратной связи: изменил файл — сразу увидел результат. Удобно учиться и отлаживать.

Конкурентность

Goroutines и каналы — позже в курсе. Сегодня важно: язык заточен под параллельную работу сервиса.

Стандартная библиотека

HTTP, JSON, тестирование — без зоопарка зависимостей на старте. Меньше шума, больше сути.

Один стиль

gofmt, понятные пакеты, явные ошибки. Код курса и код индустрии читаются похоже.

Окружение

Toolchain: три команды

Привыкаем к циклу «пишешь — собираешь — запускаешь». Модуль — паспорт проекта.

go run

Собрать и сразу выполнить. Для черновиков и проверки идеи.

go build

Получить бинарник. То, что потом положим в Docker.

go mod

Имя модуля, зависимости, воспроизводимая сборка.

Минимальная программа

Переменные

Создание: объявление, определение, инициализация

Объявление

Имя и тип: «есть переменная title типа string». Компилятор знает, чем можно пользоваться.

Определение

Под имя выделяется память. В Go var сразу определяет: без значения получите нулевое — 0, "", false.

Инициализация

Первое значение. Можно в том же var или коротко через :=.

var title string            // объявили и определили: title == ""
var done bool = false       // объявили, определили, инициализировали
count := 0                  // := только внутри функции, тип выводится

Типы

Простые типы

Тип фиксирован. Неявного приведения нет: int и int32 — разные типы.

Целые со знаком

int — «родной» размер платформы (обычно 64 бита). Дальше явно: int8, int16, int32, int64.

Беззнаковые

uint, uint8 … uint64. byte — это псевдоним uint8. Для счётчиков и сырых байт.

Дробные

float32 и float64. В обычном коде берите float64 — это тип по умолчанию для литералов вроде 3.14.

bool

Только true и false. Нулевое значение — false. Число в условие не подставишь: это не C.

Типы

Более сложные типы

Собираются из простых: список, текст или словарь «ключ → значение».

Массив [n]T

Длина — часть типа: [3]int и [4]int разные. Значение копируется. Сам по себе нужен редко.

Слайс []T

Окно на массив: длина и ёмкость. Растёт через append. Рабочая коллекция в Go — почти всегда слайс.

Строка

Неизменяемая последовательность байт в UTF-8. len(s) — байты, не руны. Склеивание даёт новую строку.

map [K]V

Словарь: ключ → значение. Писать в nil map нельзя — сначала make или литерал. Порядок ключей не гарантирован.

Типы · массив

Длина — часть типа

[3]int и [4]int — разные типы. Присваивание копирует все элементы.

a := [3]int{1, 2, 3}
b := a          // копия, не ссылка
a[0] = 9
fmt.Println(b[0])  // 1 — b не изменился
Интересно

Массив — значение. Передача в функцию тоже копирует. Поэтому в коде почти всегда слайс: дешёвый заголовок, а не все элементы.

Типы · слайс

Окно на массив

У слайса три поля: указатель, длина, ёмкость. append дописывает в хвост — или выделяет новый массив.

s := []int{1, 2, 3, 4}
fmt.Println(len(s), cap(s))  // 4 4
t := s[1:3]                  // 2, 3 — общее хранилище
fmt.Println(len(t), cap(t))  // 2 3
t[0] = 99
fmt.Println(s)               // [1 99 3 4]
s = append(s, 5)
fmt.Println(len(s), cap(s))  // 5 8
Интересно

Два слайса могут смотреть в один массив: правка одного меняет другой. Если append не влезает в ёмкость — память новая, связь рвётся.

Типы · строка

Байты и руны

Строка неизменяема. Под капотом — UTF-8. Один и тот же текст по-разному выглядит, если идти байтами или буквами.

Байты

len и s[i] работают с сырыми байтами. Для кириллицы буква — не один индекс.

s := "привет"
fmt.Println(len(s))      // 12, не 6
fmt.Println(s[0], s[1])  // 208 191 — не «п»
b := []byte(s)
fmt.Println(len(b))      // тоже 12

Руны

[]rune и range идут символами Unicode. Индекс в range — всё равно смещение в байтах.

s := "привет"
r := []rune(s)
fmt.Println(len(r))         // 6
fmt.Println(string(r[0]))   // п
for i, ch := range s {
    fmt.Println(i, string(ch)) // 0 п, 2 р, 4 и…
}

Типы · map

Ключ → значение

Словарь. Ключ должен быть сравнимым: int, string — да, слайс — нет. Порядок обхода не обещан.

var m map[string]int   // nil
fmt.Println(m["x"])     // 0 — читать можно
// m["x"] = 1           // panic: запись в nil
m = make(map[string]int)
m["x"] = 1
v, ok := m["y"]         // 0, false — ключа нет
Интересно

Читать из nil map безопасно, писать — нет. Запрос с ok отличает «ключа нет» от «значение ноль». Порядок ключей специально случайный.

Управление

if / else и switch

if / else

Скобки вокруг условия не нужны, фигурные — обязательны. Можно объявить переменную прямо в if.

if n == 0 {
    fmt.Println("пусто")
} else if n == 1 {
    fmt.Println("одна задача")
} else {
    fmt.Println("несколько")
}

switch / case

Ветки не проваливаются дальше — break не нужен. Есть default, можно сравнивать выражения.

switch status {
case "todo":
    fmt.Println("в работе")
case "done":
    fmt.Println("готово")
default:
    fmt.Println("неизвестно")
}

Управление

Циклы: один for, четыре формы

Отдельного while и do-while нет — всё пишется через for.

С предусловием

Как while: сначала проверка, потом тело. Если условие ложно сразу — тело не выполнится.

for n > 0 {
    n--
}

С постусловием

Тела нет do-while: тело хотя бы раз, проверка в конце, выход через break.

for {
    n--
    if n <= 0 {
        break
    }
}

Итерационный

Инициализация, условие, шаг — классический счётчик.

for i := 0; i < 3; i++ {
    fmt.Println(i)
}

while true

Бесконечный цикл. Выход только изнутри: break, return.

for {
    // пока не break
}

Функции

Входные, выходные, ошибка

имя addTask
входные — первые скобки (title string)
выходные — вторые скобки (Task, error)

Их может быть несколько

И на входе, и на выходе — список, не один слот. Здесь на выходе два значения: задача и статус.

error — обычно последним

Договорённость Go: полезная величина, затем ошибка. nil — ок. Это значение, не исключение.

func addTask(title string) (Task, error) {
    if title == "" {
        return Task{}, errors.New("пустой заголовок")
    }
    return Task{Title: title}, nil
}

Домашка

Папки в терминале

Переходы по меню. Папки — место, куда на занятии 02 лягут задачи.

Что должно быть

  • Главное меню: список папок и выход. for { } + switch.
  • Внутри папки: «задач пока нет», создать, удалить, переименовать папку, назад.
  • Функции с error: пустое имя, папки нет — ошибка, не паника.
  • Без struct и списка задач. Имена папок — строки (можно слайс строк).
